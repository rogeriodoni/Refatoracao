
**`CIDCHAVES`** (`MontarUpdateLinha`/`MontarDeleteLinha`, `WHERE cidchaves = ...`): `cidchaves` is `SigOpCrr`'s actual primary key (constraint `sigopcrr_cidchaves` in `docs/schema.sql`), and the same `AddCursor` call declares it as the cursor's key field.
