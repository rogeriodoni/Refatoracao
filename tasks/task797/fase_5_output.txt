## Decisions worth flagging

- **Method name, not `ConfigurarPaginaDados`.** This legacy has no PageFrame (layout FLAT ÔÇö all `get_*`/`Say*` are direct children of the form). Inventing a Page2 would violate PILAR 1; the orchestrator's FLAT branch doesn't require that name, and it validates (`no pgf_4c_` + `.ControlSource =` present).
- **`When ÔåÆ Return(.F.)` became `ReadOnly = .T.` + `TabStop = .F.`** ÔÇö not `Enabled = .F.`, which would grey out the black text the dump declares (`ForeColor = 0,0,0`). `ReadOnly` alone still lets Tab land on the field; `TabStop = .F.` is the other half of `When`. Matches the `FormSIGOPCCO` precedent, plus the Tab fix.
- **Labels: `AutoSize = .F.` + explicit `Width`, `Alignment = 0`.** Class `say` is AutoSize/left-aligned, so the dump declares only Caption/Left/Top; `AutoSize = .T.` is a no-op under `AddObject` (stays at the 100px default and would invade the TextBox). `ForeColor = RGB(90,90,90)` ÔÇö white would be invisible on the light `new_background.jpg`.
- **`MaxLength` from the schema, not pixels.** Verified against `docs/schema.sql` (UTF-16): `SigCdFrp.emps char(3)`, `tipos char(5)`, `series char(5)` ÔÇö matching the dump exactly.
- **`TabIndex` is transcribed but VFP9 renormalizes it** (each `.TabIndex = 1` pushes earlier ones down, so runtime shows 3/2/1). Documented in the method header; immaterial since `TabStop = .F.` keeps these out of the tab order.
