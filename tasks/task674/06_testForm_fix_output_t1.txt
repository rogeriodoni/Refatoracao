I found the cause: `InicializarForm` was setting `THIS.Visible = .T.` on the form itself (not just a child container), which activates the form window immediately during `Init()` ÔÇö before the test harness's `Show()` call. Once activated, VFP9 locks `WindowType` as read-only, so `TestFormWrapper.prg`'s `loc_oForm.WindowType = 0` (used to force non-modal for unattended testing) then fails with `Property WINDOWTYPE is read-only`.

The reference form `FormSIGOPBOL` (the dialog this form's own "Boleto" button opens, same flat OPERACIONAL pattern with no PageFrame) only calls `THIS.TornarControlesVisiveis(THIS)` in `InicializarForm` and never touches the form's own `.Visible` ÔÇö it lets the caller's `Show()` do that, which is the correct pattern.

I removed the stray `THIS.Visible = .T.` line in `FormSigPrSdd.InicializarForm`, keeping `TornarControlesVisiveis(THIS)` (which still makes all child controls visible, since `AddObject` creates them hidden by default). The BO file needed no changes. No other logic, fields, or lookups were touched.
