All 5 blocks now correctly reference `.Column1.Check1.*` only (the CheckBox already installed on the Column by `GarantirCheckBoxColuna`), with no remaining attempt to `AddObject` a CheckBox directly onto the Grid.

## Root cause

In `CarregarDados()`, each of the 5 grid-binding blocks (Empresas, Tipos, GrandeGrupo, GrupoProduto, Operacoes) called `THIS.GarantirCheckBoxColuna(...)` first ÔÇö which correctly does `par_oColuna.AddObject("Check1", "CheckBox")` on the **Column**. Right after that, inside `WITH loc_oPag.grd_4c_X` (where `.` refers to the **Grid**, not the Column), the code repeated `.AddObject("Check1", "CheckBox")`. A Grid only accepts `AddObject` for `Column` objects ÔÇö adding a `CheckBox` straight to a Grid throws `Cannot add this object to a Grid.`, which happened inside the `TRY` of `InicializarForm`, so `CREATEOBJECT` returned `.F.` and the form never opened.

## Fix

Removed the duplicate/erroneous `.AddObject("Check1", "CheckBox")` + `.Check1.*` (grid-level) lines from all 5 blocks, keeping the valid `.Column1.Check1.*` property assignments that configure the CheckBox already installed by `GarantirCheckBoxColuna`. No logic, lookups, or fields were altered ÔÇö only the invalid duplicate `AddObject` call was removed.
