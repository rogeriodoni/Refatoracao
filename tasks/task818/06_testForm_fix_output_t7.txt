**Root cause**: In `FormSigOpVdi.prg`'s `CarregarDados()`, five `WITH loc_oPag.grd_4c_<X>` blocks (Empresas/Tipos/GrandeGrupo/GrupoProduto/Operacoes) called `.AddObject("Check1", "CheckBox")` where `.` resolved to the **Grid** object itself (not `.Column1`), since the `WITH` was opened on the grid. VFP9 grids can't host an arbitrary `AddObject`'d control directly ÔÇö only Columns/Headers can ÔÇö hence `Cannot add this object to a Grid.` This happened on the very first instantiation (`InicializarForm` ÔåÆ `CarregarDados`), so `CREATEOBJECT` returned `.F.` and the form never opened.

The CheckBox was already being created correctly by `GarantirCheckBoxColuna(par_oColuna, ...)` (called just before each block, targeting `Column1`), making the second `AddObject` purely duplicate and broken. I removed the 9-line duplicate block (`.AddObject("Check1","CheckBox")` + 8 `.Check1.*` lines) from all five occurrences, leaving the legitimate `.Column1.Check1.*` property assignments intact.
