## Summary

**Root cause**: In `FormSigOpVdi.prg`, `CarregarDados()` installs the marker CheckBox on each grid column via `THIS.GarantirCheckBoxColuna(...Column1, ...)`, which correctly does `par_oColuna.AddObject("Check1", "CheckBox")` (adding to the **Column**, the only object VFP9 allows `AddObject` to target on a Grid's child). But right after, each `WITH loc_oPag.grd_4c_*` block redundantly repeated `.AddObject("Check1", "CheckBox")` ÔÇö except `.` there is scoped to the **Grid** itself (not `Column1`), since the WITH opens on the grid. Adding a `CheckBox` directly to a `Grid` object is invalid in VFP9 and threw `Cannot add this object to a Grid.`, which failed `InicializarForm` and made `CREATEOBJECT("FormSigOpVdi")` return `.F.` in the test harness.

**Fix**: Removed the redundant `.AddObject("Check1", "CheckBox")` + 8 duplicate `.Check1.*` property lines in all 5 grid blocks (`grd_4c_Empresas`, `grd_4c_Tipos`, `grd_4c_GrandeGrupo`, `grd_4c_GrupoProduto`, `grd_4c_Operacoes`) inside `CarregarDados()`. The correct `.Column1.Check1.*` assignments immediately above (operating on the control that `GarantirCheckBoxColuna` already installed) were left untouched ÔÇö no behavior or geometry was lost, just the invalid duplicate `AddObject` calls.

No other files needed changes.
