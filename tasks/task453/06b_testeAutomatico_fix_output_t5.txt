**Root cause identified**: Formint.prg declared `ShowWindow = 0` and then immediately overrode it with `ShowWindow = 1` in the same class property block. VFP9's last-wins rule made the effective value `1`. In headless mode (`-T`), `ShowWindow = 1` causes VFP to try positioning the form as a child of the active MDI window ÔÇö which doesn't exist headlessly ÔÇö blocking indefinitely. This is why ALL 5 timeout runs had **zero output**: VFP hung before executing even the first `?` statement in TesteAutomatico.

The CorretorAutomatico pattern #29 detects this and adds `ShowWindow=0` when absent, but it failed to catch the case where `ShowWindow=0` already existed (so it skipped the file) while `ShowWindow=1` was overriding it below.
