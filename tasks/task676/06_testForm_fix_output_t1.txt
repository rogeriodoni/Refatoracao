Fixed. The three `TextBox` controls in `cnt_4c_Operacao` (`txt_4c_Codigo`/`txt_4c_Empresa`/`txt_4c_Operacao`) had `.ControlSource` pointing at `tmpnens.numps/emps/dopps` unconditionally at creation time. That cursor belongs to the **parent form** (as the file's own header documents) and only exists when this dialog is opened by it ÔÇö when the test harness instantiates `FormSigPrSer` standalone, `tmpnens` doesn't exist yet, so assigning `ControlSource` inside `ConfigurarPaginaDados()` crashed immediately (`Alias 'TMPNENS' is not found`, line 596), which made `InicializarForm` return `.F.` and `CREATEOBJECT` return NULL.

Wrapped each assignment in `IF USED("tmpnens")`, consistent with the file's own documented pattern (regra #41/CLAUDE.md ÔÇö binding to a not-yet-existing alias). In production use (parent form already has `tmpnens` populated before opening the dialog), behavior is unchanged; in standalone/test mode the fields just stay unbound instead of crashing the form's initialization.
