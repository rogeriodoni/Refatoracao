**Root cause**: `InicializarForm()` set `THIS.Visible = .T.` directly, which creates the actual window handle immediately during `CREATEOBJECT()` ÔÇö before `TestFormWrapper`/`menu.prg` ever calls `.Show()`. Once the window exists, VFP9 locks `WindowType` (modal/modeless can't change after the window is realized), so the harness's `loc_oForm.WindowType = 0` (needed to force non-modal for automated testing) throws "Property WINDOWTYPE is read-only."

This exact defect and fix already exist in two sibling forms (`FormSIGOPCFE`, `FormSigOpGvt`) with a documented comment. I removed the premature `THIS.Visible = .T.` from `FormSigOpImg.prg`'s `InicializarForm`, leaving visibility exclusively to the external `.Show()` call ÔÇö the `IF THIS.Visible` guards elsewhere in the file (SetFocus calls in `OrdenarPorColuna`/`AjustarControlesPorModo`) already correctly no-op during initialization.
