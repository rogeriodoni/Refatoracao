The fix looks correct and the surrounding comment now explains the real cause.

**Root cause**: `FormatarColunasGrade` was setting `.ControlSource` directly on the CheckBox child control (`loc_oGrid.Column2.chk_4c_Check1.ControlSource`) instead of on the Column itself. VFP9 only allows data-binding through `Column.ControlSource` (which then applies to whichever control is `CurrentControl`) ÔÇö assigning it directly to the child throws `Parent object will not allow this property setting`. That error was being caught by `MontaGradeEtiquetas`'s TRY/CATCH, which aborted the whole binding sequence before `GO TOP`/`Refresh`, leaving the grid unbound regardless of database connectivity ÔÇö this is what was actually breaking the `CarregarDadosReais` test, not the (expected, benign) "Connection handle is invalid" messages from `CarregarParametrosSistema`/`CarregarTiposEtiquetaDinamico` running without a DB in the test harness.

**Fix**: changed `loc_oGrid.Column2.chk_4c_Check1.ControlSource = ...` to `loc_oGrid.Column2.ControlSource = ...`, consistent with how Column4/Column10 (the other custom-control columns) already bind correctly on the Column level in `MontaGradeEtiquetas`.
