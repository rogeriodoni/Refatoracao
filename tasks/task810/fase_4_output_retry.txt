## A real bug the probes caught

My first version crashed with `Unknown member COLUMN1`. Measuring in VFP9 showed why:

```
apos CREATEOBJECT      ColumnCount=3
apos USE IN do alias   ColumnCount=0   <- Column objects destroyed
apos reabrir o cursor  ColumnCount=0   <- reopening does NOT restore
apos RecordSource=     ColumnCount=3   <- only the rebind restores
```

Closing the bound alias collapses `ColumnCount` and destroys the columns. Critically, restoring `ColumnCount` *recreates* them, so it isn't only widths and captions that are lost ÔÇö fonts, `ReadOnly` and colors go too. So `AplicarFormatoGrade` now covers **every** column property (minus `ControlSource`), guards on `ColumnCount`, and the funnel restores a collapsed `ColumnCount` before rebinding.
