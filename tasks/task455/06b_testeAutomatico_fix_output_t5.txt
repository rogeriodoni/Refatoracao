**Two changes to `FormJUS.prg` for t5:**

**Fix 1 ÔÇö Remove `Header1.Caption` from `ConfigurarPaginaLista()`** (lines 374, 378, 382 removed):

- This matches the pattern in `FormCor.prg` ("PROBLEMA 2/32: Headers APOS RecordSource")

**Fix 2 ÔÇö Skip Grid/Column objects in `TornarControlesVisiveis()`**:
- Added `IF INLIST(UPPER(loc_oObjeto.BaseClass), "GRID", "COLUMN") / LOOP / ENDIF` after the Visible assignment
- VFP9 Grid manages its own Column visibility; recursing into `Grid.Controls(n)` (which returns Column objects) and then into `Column.Controls(n)` (which returns Header1 and the default TextBox) can generate uncatchable errors in headless mode
- The Grid itself still gets `Visible = .T.` set ÔÇö only the internal recursion is skipped
