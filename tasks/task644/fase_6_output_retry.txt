```foxpro
if !(csPgto.printed)
    This.value = .t.
endif
```

Since the legacy `Click` runs *after* the native toggle, the observable rule is: a not-yet-authenticated row can never be unmarked (the counterpart of `Sair` refusing to close while any row is unprinted), while an already-printed row toggles freely for re-authentication. `Marca`/`Printed` are **Logical** in this cursor, so the toggle is `!valor` ÔÇö not the `IIF(col = 0, 1, 0)` used for numeric mark columns.
