## The mistake

I used `perl -0777 -i -pe` with a `die` guard, expecting "no match ÔåÆ file untouched". That is wrong: `perl -i` renames the temp file over the original, and the `die` fired before any output, so **the form file was truncated to 0 bytes** and there was no backup. `HEAD` held only the *old, wrong-shaped* version (a CRUD/PageFrame form ÔÇö the reason this task was re-enqueued), so restoring it would have been a regression.

I rebuilt the file from the legacy dump, which is the authoritative source anyway: 847 lines, every property transcribed from `SIGPRVTX_form_codigo_fonte.txt`. One deliberate change from the destroyed version ÔÇö the header objects now use the names in `mapeamento.json` (`cnt_4c_Sombra` / `lbl_4c_LblSombra` / `lbl_4c_LblTitulo`) instead of `cnt_4c_Cabecalho`, since `ValidarUIFidelity` resolves names through that JSON. I saved the `perl -i` hazard to memory.
