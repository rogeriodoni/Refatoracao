Fixed `FormSigOpGvt.prg`. Root cause: `InicializarForm()` called `THIS.Visible = .T.` directly, which realizes the window during `CREATEOBJECT` (before any external `.Show()` runs). Once a form window is realized, `WindowType` becomes read-only ÔÇö and `TestFormWrapper.prg` always does `loc_oForm.WindowType = 0` before its own `.Show()` to force non-modal headless testing, so that assignment threw `Property WINDOWTYPE is read-only.`

This exact defect/fix is already documented in the sibling form `FormSIGOPCFE.prg` ("NUNCA atribuir THIS.Visible = .T. aqui"). I removed the self-show line, replaced it with the same warning comment, and updated the file header to make `.Show()` an explicit, required step for callers.

No BO change was needed ÔÇö `SigOpGvtBO.prg` is untouched.
